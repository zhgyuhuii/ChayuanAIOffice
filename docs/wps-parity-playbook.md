# WPS 顶部菜单像素级对齐 —— 主开发清单（Playbook）

> 目标：顶部菜单的**顺序、功能、下拉内容、布局尺寸**与 WPS 一一对应。
> 用法：每行 = 一个施工单元，含【状态｜处理思路】。状态：✅ 已完成（附提交号）｜◐ 部分完成｜⬜ 未做。
> 处理思路写到"改哪个文件/哪个机制"粒度，照单施工即可，无需再调研。
> 依据：31 张 WPS 截图逐位置记录（`~/Downloads/wps-screen/`）+ 三端脚本提取（`t()` 键→zh）+ 实码确认 + 官方资料核对。
> 配套文档：`docs/wps-menu-item-audit.md`（差距审计）、`docs/wps-ribbon-parity.md`(宏观对照)。日期 2026-09-03。
