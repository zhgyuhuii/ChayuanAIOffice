## 一句话说明

察元AI Office 用一条 Chrome 式标签条承载所有文档：首页标签常驻第一格不可关闭，「+」新建文档，标签可拖动排序、拖出窗口（tear-off）再拖回合并、双击就地重命名文件；后台标签过多时长时间没看的会自动休眠省内存，回到它时自动重开。

## 适用场景

- 同时处理多份文档，想用标签或双窗口并排对照；
- 文件名起错了，不想离开编辑器去文件管理器改名；
- 开了很多标签后电脑变卡，或发现某个后台标签点开要重新加载，想弄清原因。

典型提问（chabot 语料视角）：

- 「标签页能拖出来变成独立窗口吗？能再拖回去吗？」
- 「为什么后台标签点开要重新加载？」
- 「怎么重命名正在编辑的文件？」

## 前置条件

- 桌面壳形态。标签条是壳窗口顶部的一条：macOS 左端是原生红绿灯；Windows/Linux 左端有「**菜单**」按钮、右端是自绘的「最小化/最大化/关闭」窗口控制。

## 操作步骤

**1. 认识标签条**

从左到右：（mac 红绿灯或 Windows/Linux 的「菜单」按钮与窗口控制）、「**折叠/展开左栏**」按钮（只影响主页左栏，中栏对话不可折叠）、标签条本体、带「+」的「**新建标签页**」按钮、「**全部标签**」溢出按钮。

- **首页标签**：第一格，产品 logo +「察元AIOffice」，永久常驻、没有关闭 ×、拖动排序时也不能越过它；
- **文档标签**：带格式图标（docx/xlsx/pptx/pdf/md/html）或手册图标（按 F1 打开的应用内手册）；按下即激活；悬停显示两行提示——第一行标题、第二行完整路径（休眠标签会附加「(已休眠)」）；
- 每个可关标签右侧有「**关闭标签**」× 按钮；**鼠标中键点击标签**也可直接关闭。

**2. 新建标签**

点「**+**」弹菜单：「新建」分节下「文档 / 表格 / 演示稿 / MD文档 / HTML文档 / PDF文档」六项 + 分隔线 + 「打开…」。新建文档见《O03 新建与打开文件》。

**3. 标签太多时：「全部标签」列表**

标签条放不下或想快速跳转时，点右端「**全部标签**」按钮：弹出全部标签的清单（带文件类型图标，当前标签勾选显示），点任意一项切换过去。标签条放不下时也可在条上横向滚动（触控板直接滚，鼠标滚轮上下滚动会转为横向）。

**4. 双击标签：就地重命名文件**

双击某个文档标签，标签文字变为输入框（预填完整文件名，含扩展名）：`Enter` 或点别处提交，`Esc` 取消。改名走真实的文件重命名，打开中的文件标题与左栏列表同步更新。两点限制：

- 首页标签和未命名（从未保存）的文档不能这样重命名；
- 改成别的编辑器管不了的扩展名会被拒绝，提示「重命名不能改变文件类型」（例如 .docx 改成 .md）；改成同一编辑器支持的其他扩展名（如 .md 改 .txt）允许。

**5. 拖动排序**

按住标签左右拖动：标签 1:1 跟手，中间的标签实时让位，松手后顺序提交。

**6. 拖出独立窗口（tear-off）与拖回**

- 把一个文档标签**向下或向上拖离标签条**（约 28 像素以上），它就撕出成一个独立窗口——窗口跟着手里没松开的指针走，松手落定；文档连同未保存的编辑一起移动，不重新加载；
- 把独立窗口的标题栏拖回壳窗口标签条上方并稍作停留，标签条出现插入位置指示，窗口自动折回成标签插到该位置；
- 独立窗口使用系统原生边框，带各自的未保存改动关闭确认，可以和主窗口并排对照文档。

**7. 标签右键菜单**

- 文档标签右键：「**关闭**」「**关闭其他**」「**关闭左侧**」「**关闭右侧**」「**关闭全部**」；
- 首页标签右键：只有「**关闭全部**」——它只关文档标签，首页永远留着。

**8. 后台标签休眠（省内存机制）**

每个文档标签是一个独立渲染进程。为避免标签开多后内存吃紧，默认开启休眠（设置 ▸ 常规 ▸「**休眠不活跃的标签页**」，开关默认开，说明文案：「标签页多到一定数量后，长时间没有查看的会释放内存；回到它时会重新打开文件。有未保存修改或已固定的标签页不会休眠。」）：

- 活标签上限随机身内存定：8GB 及以下保 4 个，16GB 保 8 个，32GB 及以上保 12 个；
- 超出上限时，最久没看的后台标签在闲置满 10 分钟后按最旧优先逐个休眠（每分钟巡检一次；内存超预算时不再等闲置时间，每次巡检让最旧的一个休眠）；
- 休眠标签的标签页仍留在条上（悬停提示带「(已休眠)」），点它时按文件重新加载——你只会感到「回到标签时它重新打开了」，未保存修改的标签不会被休眠。

### 验证

1. 连续「+」新建三个文档标签：三个标签依次排在首页标签之后；按住中间一个左右拖，松手后顺序按拖动结果排列。
2. 把一个已保存文件（如 .md）的标签向上拖离标签条：出现独立窗口且内容不重载；把该窗口拖回标签条上方停留，它折回成标签。
3. 双击一个已保存文档的标签：出现重命名输入框，改名后标签标题、文件名同步更新；尝试把 .docx 改成 .md 会被拒绝并提示「重命名不能改变文件类型」。
4. 开超过机器档位数量的标签并闲置十余分钟，后台标签悬停提示出现「(已休眠)」，点回时重新加载文件。

## 常见问题

**Q1：首页标签能关掉吗？**
不能，它就是常驻主页（文件与对话工作台）的入口，右键也只有「关闭全部」且不会关掉首页本身。

**Q2：点一个后台标签，为什么内容要重新加载？**
它刚才被休眠回收了内存（见第 8 步）。文件内容从磁盘重新打开，未保存的改动不会丢——有未保存修改的标签根本不会被休眠。不想要这个行为可在 设置 ▸ 常规 关掉「休眠不活跃的标签页」。

**Q3：想两个文档并排看，怎么办？**
把其中一个标签拖出成独立窗口，再手动把两个窗口并排摆放；独立窗口随时可拖回标签条合并。

**Q4：双击重命名时把扩展名改了，会有问题吗？**
改成应用不支持路由的扩展名会被直接拒绝（「重命名不能改变文件类型」）；改成同一编辑器支持的扩展名（如 .md→.txt、.csv→.tsv）允许，文件会继续用原编辑器打开。

**Q5：关掉的标签能找回吗？**
标签右键菜单没有「重新打开已关标签」一类的入口；误关的文件可从主页「最近」列表或文件夹树里重新点开。

## 形态差异

- **Windows/Linux**：标题栏隐藏，窗口「最小化/最大化（还原）/关闭」由标签条两端自绘按钮承担，左端多一个「菜单」按钮弹出应用菜单（文件/编辑/视图等）；macOS 用原生红绿灯与顶部菜单栏。
- **web/dsh 插件形态**：浏览器里的五编辑器没有这条标签条与 tear-off 行为。
