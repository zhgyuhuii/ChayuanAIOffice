## 一句话说明

Docs 文档编辑器顶部的功能区按 Word 习惯分成一排页签：开始、插入、绘图、设计、布局、引用、审阅、察元 AI、视图（macOS 不显示「文件」，Windows 在最左多一个「文件」），进表格、选中图片、编辑页眉页脚时还会临时多出上下文页签。本篇按页签把每个分组的主干按钮过一遍，并讲清功能区折叠/紧凑密度与导航窗格。

## 适用场景

- 刚从 Word/WPS 迁过来，想知道某个功能（首字下沉、域、交叉引用、分栏……）放在哪个页签哪个组；
- 功能区被折叠了或只剩一排图标，不知道怎么恢复；
- 想用导航窗格按标题大纲快速跳转、调整章节结构。

典型提问（chabot 语料视角）：

- 「Docs 顶部那一排页签都各管什么？」
- 「功能区只剩图标了/整个命令区不见了，怎么恢复？」
- 「文档大纲/导航窗格在哪里打开？」

## 前置条件

- 在察元AI Office 中用 Docs 编辑器打开了一个文档（新建/打开见 [O03](./O03-新建与打开文件.md)）。
- 大部分按钮在无文档时置灰；绘图、视图的部分开关（如深色模式）不受此限。

## 操作步骤

**第 1 步 · 认识页签行：固定页签 + 上下文页签 + 密度**

1. 页签行固定顺序（macOS）：开始 / 插入 / 绘图 / 设计 / 布局 / 引用 / 邮件 / 审阅 / 察元 AI / 视图；Windows 在最左多一个「**文件**」按钮，点开是菜单：打开（Ctrl+O）、保存（Ctrl+S）、另存为（Ctrl+Shift+S）和四项转换。macOS 没有这个页签——文件动作在系统菜单栏。
2. 光标进入**表格**会临时多出「**表格设计**」「**表格布局**」两个上下文页签；选中**图片**多出「**图片格式**」；编辑**页眉页脚**时多出页眉页脚页签。离开对应对象后自动消失，回到之前的常规页签。
3. 功能区密度三档：
   - 折叠/展开命令区：macOS 按 **⌥⌘R**（Windows 为 **Ctrl+F1**），或**双击任意页签**、或再点一次当前页签；折叠后只剩页签行，点任意页签即展开并显示该页签内容。状态会记住，下次打开保持。
   - 紧凑（仅图标）：macOS 按 **⌥⌘K**（Windows 为 **Ctrl+Alt+K**）在完整/紧凑间切换；把鼠标悬停在当前页签上能看到这两条快捷键提示。

**第 2 步 · 「开始」页签：转换 / 剪贴板 / 字体 / 段落 / 样式 / 编辑**

- 「**转换**」组（最左）：「**转换为 PDF…**」「**转换为 HTML…**」「**转换为 Markdown…**」「**导出为图片…**」——导出图片会先让你选保存文件夹，然后逐页导出成 `<文件名>-01.png`、`-02.png`…（先转 PDF 再逐页栅格化）。打印不走功能区：按 **⌘P**（应用快捷键清单里的「打印」）弹出「**打印**」对话框，可选打印范围后送打印机。
- 「**剪贴板**」组：「**粘贴**」（右侧箭头有「**选择性粘贴…**」，可按 HTML/无格式 Unicode 文本/图片粘贴）、「**剪切**」「**复制**」「**格式刷**」（点一下刷一次，激活后再点取消）。
- 「**字体**」组：**东亚字体**与**西文字体**分开两个下拉（中西文可各用一种字体）；字号、增大/减小字号；加粗 ⌘B、倾斜 ⌘I、下划线 ⌘U、删除线、上标/下标；「**文本突出显示颜色**」「**字体颜色**」（含主题颜色/标准色/其他颜色…）；「**更改大小写**」下拉（句首字母大写/小写/大写/每个单词首字母大写/切换大小写/半角/全角）；「**清除所有格式**」。
- 「**段落**」组：「**项目符号**」「**编号**」「**多级列表**」（可自定义）、增减缩进量、「**显示/隐藏编辑标记**」、左/中/右/两端对齐（⌘L/⌘E/⌘R/⌘J）、文字方向（从左到右/从右到左）、「**行距**」（含「**行距选项…**」）、段落底纹、各边框线（下框线/上框线/所有框线/无框线等）。
- 「**样式**」组：样式库（正文/标题 1/标题/强调等，打开「**样式窗格**」可查看、应用和修改文档中的全部样式）。
- 「**编辑**」组：「**查找**」「**替换**」「**全选**」。

**第 3 步 · 「插入」页签：页面 / 表格 / 插图 / 文本 / 链接 / 批注 / 页眉和页脚 / 符号**

- 「**页面**」组：「**封面**」（预设封面画廊，可「**删除当前封面**」）、「**空白页**」、「**分页符**」。
- 「**表格**」组：「**表格**」——悬停网格选行列，或「**插入表格…**」对话框。
- 「**插图**」组：「**图片**」、「**图表**」（打开图表设计器，图表库为 ECharts，共 39 类、含 3D/GL；插入的是真图表对象，数据可再编辑）、「**形状**」。
- 「**文本**」组：「**文本框**」（绘制文本框/简单文本框）、「**艺术字**」（12 种预设，如「填充：蓝色」「填充：金色」）、「**首字下沉**」（无/下沉/悬挂）、「**域**」——「日期」「时间」「页码(当前页)」「总页数」「文件名」五种。
- 「**链接**」组：「**链接**」「**书签**」「**交叉引用**」。
- 「**批注**」组：「**批注**」按钮（先选中文字，见 [O18](./O18-批注与修订.md)）。
- 「**页眉和页脚**」组：「**页眉**」「**页脚**」（可编辑内容/移除）、「**页码**」（页眉或页脚的左/中/右六个位置，另有「**设置页码格式…**」与「**移除页码**」）。
- 「**符号**」组：「**符号**」「**公式**」。

**第 4 步 · 「绘图」页签：墨迹批注**

- 「**选择**」组：「选择」工具（恢复正常编辑）。
- 「**绘图工具**」组：「**笔**」「**荧光笔**」「**橡皮擦**」。
- 「**笔样式 / 荧光笔样式**」组：10 种颜色色板；笔的粗细 1/2/3.5/5 像素，荧光笔 6/10/16 像素。
- 「**清除**」组：「**全部清除**」清掉所有墨迹。墨迹是覆盖在页面上的批注层，不改正文文字。

**第 5 步 · 「设计」与「布局」页签：整篇外观**

- 「设计」分两组：「**文档格式**」——「**主题**」及配套的「**颜色**」「**字体**」；「**页面背景**」——「**页面颜色**」「**水印**」（含「机密」等预设、「**自定义文字水印…**」、「**删除水印**」）、「**页面边框**」。
- 「布局」分三组：「**页面设置**」——「**页边距**」（含自定义）、「**纸张方向**」（纵向/横向）、「**纸张大小**」、「**分栏**」（一栏/两栏/三栏）、「**分隔符**」（分页符/分栏符/自动换行符；分节符四档：下一页/连续/偶数页/奇数页）；「**段落**」——左/右缩进、段前/段后距；「**排列**」——「**位置**」（九宫格定位）与「**环绕文字**」，针对选中的浮动图片等对象。
- 「引用」页签：「**脚注**」组（插入脚注/插入尾注）、「**引文与索引**」组（题注、插入引文、添加新源…、书目、标记条目(XE)、插入索引）；「邮件」页签为邮件合并（见 [O21](./O21-邮件合并与Zotero引文.md)）。

**第 6 步 · 「视图」页签与导航窗格**

- 「**视图**」组五种形态：「**页面视图**」（按页面尺寸显示）、「**Web 版式**」、「**大纲**」、「**阅读视图**」、「**分页预览**」。
- 「**缩放**」组：「缩放」对话框、缩小/放大、「**100%**」、「**页宽**」「**整页**」「**多页**」三个适配。
- 「**外观**」组：「**深色模式**」——提示原文「以深色显示编辑区域,不改变文档内容」。
- 「**显示**」组：「**标尺**」「**网格线**」（仅用于对齐，不会打印）「**导航窗格**」。
- 「**窗口**」组：「**新建标签**」（再开一个本文件的标签）、「**拆分**」（同文档上下分栏）、「**切换标签**」（列出所有 Docs 标签跳转）。
- 导航窗格：面板标题「**导航**」，三个页签——「**标题**」（大纲树，可展开/折叠）、「**页面**」（页面缩略图）、「**结果**」（顶部搜索框输入即全文搜索）。**点击标题**跳到正文对应位置；**右键标题**弹出菜单：「**升级**」「**降级**」「**在前面新建标题**」「**在后面新建标题**」「**删除**」（连同该标题下整块内容一起删）、「**选择标题和内容**」，面板级还有「**全部展开**」「**全部折叠**」和「**显示标题级别**」（只显示到第 N 级）。

「审阅」页签（批注/修订/比较/保护）见 [O18](./O18-批注与修订.md)；「察元 AI」页签（校对/文本分析/思维导图等）见 [O19](./O19-察元AI页签校对与文本分析.md)。

### 验证

1. 切到「视图」页签点「导航窗格」：左侧出现「导航」面板，「标题」页签按层级列出文档标题；点一个标题，正文滚动到对应位置；右键标题应弹出升级/降级/删除等菜单。
2. 按 **⌥⌘K**：功能区命令区变成只剩图标的一行；再按一次恢复。按 **⌥⌘R**（Windows Ctrl+F1）：命令区整个收起只剩页签行；点任意页签它又展开。
3. 「开始」→「转换」→「转换为 PDF…」：出现保存对话框，确认后状态栏提示导出完成的文件路径。

## 常见问题

**Q1：功能区命令区整个不见了，只剩页签？**
这是折叠状态。点任意一个页签即可临时展开；要恢复常驻，按 ⌥⌘R（Windows Ctrl+F1）或双击页签。折叠状态会记忆，重启后仍保持，需再按一次快捷键切回。

**Q2：按钮都变成了小图标，字没了？**
那是「紧凑（仅图标）」密度，按 ⌥⌘K（Windows Ctrl+Alt+K）切回完整显示。

**Q3：为什么页签行有时多出「表格设计/表格布局」「图片格式」？**
上下文页签：光标进了表格、选中了图片、或在编辑页眉页脚时自动出现，离开对象自动消失，不需要找开关。

**Q4：macOS 上找不到「文件」页签，打开/保存在哪？**
macOS 版没有「文件」页签，打开、保存、另存为在窗口上方的系统菜单栏里；Windows 版在功能区最左侧的「文件」按钮里。「转换」四项在两个平台都同时挂在「开始」页签最左的「转换」组。

**Q5：深色模式会把文档也改成黑底吗？**
不会。按钮提示原文是「以深色显示编辑区域,不改变文档内容」——改的是界面观感，文档本身的页面颜色、打印和导出结果不受影响。

## 形态差异

- **macOS**：无「文件」页签，文件动作在系统菜单栏；折叠/紧凑快捷键为 ⌥⌘R / ⌥⌘K。
- **Windows/Linux**：页签行最左有「文件」按钮（打开 Ctrl+O / 保存 Ctrl+S / 另存为 Ctrl+Shift+S / 转换）；折叠为 Ctrl+F1、紧凑为 Ctrl+Alt+K。
