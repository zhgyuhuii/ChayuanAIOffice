## 一句话说明

「幻灯片放映」页签把演出相关的能力集中在一排：从头开始/从当前页全屏放映、演示者视图（带备注/计时/画笔，多屏时外接屏放给观众）、自定义放映、循环放映、隐藏幻灯片、排练计时、倒计时，以及最重要的——「录制」：放映的同时录下你的旁白和每页停留时间，保存后旁白随文档写入 pptx，PowerPoint 同样能播放。

## 适用场景

- 要上台投影，想知道怎么双屏放映（自己看备注、观众看大屏）；
- 需要把带讲解语音的演示稿发给别人，对方用 PowerPoint 也能放；
- 只想放文档里的一部分页，或者前台大屏循环轮播。

典型提问（chabot 语料视角）：

- 「怎么边放映边录旁白？录完存在哪？」
- 「演示者视图怎么开？外接投影仪怎么设置？」
- 「怎么只放映其中几页？」

## 前置条件

- 在察元AI Office 中用 Slides 编辑器打开了演示文稿（新建/打开见 [O03](./O03-新建与打开文件.md)）；放映类按钮在无文档时置灰。
- 录旁白需要本机麦克风并在系统弹窗里同意授权；没有可用麦克风时放映窗口会提示「没有可用的麦克风：未录制任何内容」。
- 演示者视图的「另一屏全屏放映」需要至少两台显示器；单屏也可用演示者视图（本窗口内使用）。

## 操作步骤

**第 1 步 · 认识「幻灯片放映」页签**

页签分三组：「**开始放映幻灯片**」「**设置**」「**放映到**」。

**第 2 步 · 开始放映幻灯片组**

- 「**从头开始**」：从第 1 页全屏放映（快捷键 **F5**；隐藏页跳过——若第 1 页本身是隐藏页则仍会先放它）。
- 「**从当前幻灯片开始**」：从当前选中页接着放（**Shift+F5**）。
- 「**演示者视图**」：进入演示者工作台（见第 4 步）。
- 「**自定义放映**」：把部分页按指定顺序组成一场放映（见第 5 步）。

**第 3 步 · 放映中的操作（普通放映窗口）**

- 翻页：→ / 空格 / 回车 / PgDn / 单击下一步；← / PgUp 上一页；Home/End 首末页；**数字键+回车**跳到第 N 页。
- 黑屏/白屏：**B** 或 **.** 黑屏、**W** 或 **,** 白屏（任意键或点击恢复）——中场休息不让观众看屏幕时用。
- 前进时播放目标页的**切换效果**与页内**动画**（动画按步播放，翻页键在动画放完后才翻页；后退/跳页直接显示全部动画完成态）。
- **右键**打开放映菜单（下一页/上一页/最后查看过的/显示所有幻灯片/屏幕/结束放映）。
- 放到最后一页之后出现「**放映结束。**」黑屏，单击退出（Esc 随时退出）。

**第 4 步 · 演示者视图（PresenterView）**

- 单屏：本窗口变成演示者工作台。布局：顶栏（「**结束放映**」/「**交换显示器**」/「**切换普通放映**」）；左列计时器（暂停计时/继续计时/重新计时）与时钟；中央大画面；工具栏（画笔/激光笔/清除墨迹/黑屏）+页码进度导航；右列**下一页预览**与**备注**（可调字号）；底部整排缩略图点击跳页。
- 多屏：进入演示者视图时，主进程在外接显示器上自动开一个全屏**观众放映窗口**。演示者这边是唯一驱动：翻页/动画/黑屏/墨迹同步广播过去，观众端的点击与按键回传给演示者仲裁。
- 也可以在「放映到」组勾选「**显示演讲者视图**」，普通放映时自动带上演示者工作台；「放映到」下拉可指定「**当前显示器**/**主要显示器**/**显示器 N**」。

**第 5 步 · 设置组：自定义放映、隐藏、排练、倒计时**

- 「**自定义放映**」：弹管理对话框——「**新建**」创建一场（默认名「自定义放映 N」），右侧「**在演示文稿中的幻灯片**」勾选要放的页，下方「**放映顺序**」可调整；列表页有「**放映此自定义放映**」一键开演。自定义放映清单按文档保存在本机（localStorage），不写入 pptx。
- 「**放映设置**」下拉：「**循环放映（结束后从头再放）**」——勾上后放完自动从头再来，设置真实写盘（presProps），适合展厅轮播。
- 「**隐藏幻灯片**」：隐藏当前页（保留在文档中，放映时跳过；标记写入 pptx，PowerPoint 同样识别）。再点一次取消隐藏。
- 「**排练计时**」下拉：「**开始排练**」进入排练放映，逐页演练；结束弹出「**排练计时**」对话框：「本次放映总时长 X。是否保存每页停留时间作为自动换片时间？」——「**保存**」后各页获得自动换片时间（下次自动放映按此节奏）；「**清除排练计时**」可清掉。
- 「**倒计时**」：弹「输入倒计时分钟数」（默认 10），确定后从第 1 页开始放映并在角落显示剩余时间倒计时。

**第 6 步 · 录制旁白（核心）**

1. 「**录制**」下拉选「**从头开始录制**」或「**从当前幻灯片开始录制**」。
2. 进入全屏放映，麦克风开始录音，屏幕下方出现**录制条**：「**正在录制**」红点 + 当前页用时 + 「**总时长 X**」+「**暂停**」按钮（暂停后变「继续」）。系统未授权麦克风或无麦克风时显示「**没有可用的麦克风：未录制任何内容**」。
3. 像平常一样讲解并翻页——你在一页上说的话就归那一页，一页去两次则两段都算（按排练顺序叠加）。
4. 讲完按 Esc 结束放映，弹出「**录制旁白**」对话框：「录制总时长 X。是否保存每页的旁白和停留时间？」——点「**保存**」；「**不保存**」丢弃。
5. 保存后：每页得到一段旁白音频（24 kHz 16-bit 单声道 WAV），停留时间同时写为该页自动换片时间，状态栏提示「**已为 N 页保存旁白（PowerPoint 中同样可以播放）**」；⌘S 保存文档后旁白随文件写入 pptx，PowerPoint 打开可播放。录错的页可单独重录，或用「录制」下拉的「**清除当前幻灯片中的旁白**」「**清除所有幻灯片中的旁白**」移除。

**第 7 步 · 幻灯片母版（跨页样式）**

「**视图**」页签 →「**幻灯片母版**」：全屏母版编辑视图，左列「母版 + 各版式」缩略图，右侧画布可改字体占位、加公司 Logo、调背景；改动影响所有引用该版式的页面。关闭回到编辑器后全部页面刷新。

### 验证

1. 按 F5 放映：翻页、B 黑屏、数字+回车跳页、Esc 退出均按第 3 步生效。
2. 双屏环境进「演示者视图」：外接屏应全屏显示当前页，本机显示备注/计时/缩略图，演示者翻页观众端同步。
3. 录一段旁白并保存：状态栏出现「已为 N 页保存旁白」；⌘S 保存后把 pptx 拷到装有 PowerPoint 的机器打开，切到「幻灯片放映」应能听到每页旁白、且按录制的停留时间自动换片。
4. 隐藏一页后按 F5：该页被跳过；PowerPoint 打开该文档，此页同样标记为隐藏。

## 常见问题

**Q1：点「录制」提示「没有可用的麦克风：未录制任何内容」？**
系统未授权麦克风或没有可用输入设备。到系统设置里给察元AI Office 授予麦克风权限后重新录制。

**Q2：录完旁白发给别人，对方 PowerPoint 里放不出声音？**
两步排查：① 保存旁白后是否按 ⌘S 把文档写盘（旁白随保存写入 pptx）；② 对方在 PowerPoint 放映设置里是否关闭了旁白播放。旁白按页存为 WAV，PowerPoint 原生支持。

**Q3：自定义放映在别的电脑上打不开放映清单？**
自定义放映清单目前按文档保存在本机（localStorage），不随 pptx 走；换机器需重新建一场。放映用的页顺序以文档页序为准。

**Q4：排练计时保存后，每次放映都自动翻页，怎么取消？**
「排练计时」下拉 →「**清除排练计时**」即可清掉各页的自动换片时间；「录制」保存旁白会重新写入停留时间，注意两者共用同一字段。

**Q5：F5 没反应？**
放映类按钮需要已打开文档；另外焦点若停留在其他应用窗口，快捷键不会送达。点回 Slides 窗口再按 F5。
