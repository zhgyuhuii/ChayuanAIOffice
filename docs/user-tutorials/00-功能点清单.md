# 察元AI Office（chayuan-office）用户功能点清单（user-tutorials 教程底稿）

> **用途**：本清单是 `docs/user-tutorials/` 教程集的纲——每个功能点对应一篇独立教程 md，最终整库喂给 chabot 项目作客服/问答语料。写作前必读同目录 `01-写作规范.md`。
> **产出方式（2026-10-30）**：两个只读代码盘点代理全库扫描（主壳/六编辑器/CLI/MCP/KB/授权等）产出，事实以 main 代码为准；与 README.md（v1.0.14）不一致处已在本清单与各篇「事实来源」节标注。
> **编号规则**：O 前缀单层连续编号（O01-O47），与察元OS（M/P/C/K 等）、chayuan-wps（W）教程不冲突；chabot 侧按 `office-tutorials/` 目录区分。

## 产品一句话

察元AI Office（Chayuan AI Office）——开源（Apache-2.0）AI 办公套件：文档 docx / 表格 xlsx / 演示 pptx / 真文本 PDF / Markdown / HTML 六编辑器一壳，AI 一等公民嵌入每个编辑器（首页一句话生成整套文档、就地改写带修订与回滚）；本地优先（离线 PDF 转换、扫描 OCR 全在本机）；BYOK 任意 OpenAI 兼容模型；CLI `chaoffice` + MCP Server + Agent Skill 供 Claude Code/Codex/Cursor 等智能体调用；覆盖 Windows/macOS/Linux/麒麟 UOS。

## 事实纪律要点（写作代理必读）

- 文案权威：主壳 `apps/shell/src/renderer/src/strings.ts`（A 区上游词条）+ `i18n-local-strings.ts`（B 区本地词条，22 语言块 tr 回退）；各编辑器自带 `i18n/`（docs: ribbon/app/ai/local；slides: ribbon/app/panes/ai/local；pdf: strings.ts+strings-local.ts）。抽 zh 为准。
- **LOCAL 裁定**（以 Home.tsx L3365 附近注释为准）：左上「使用手册 / AI 问答」两入口当前隐藏（F1 仍开手册；KbAskPanel 代码在位）——教程写「AI 问答」必须注明现役入口状态。
- 察元OS 教程已有 F4（Office 概览）与 K9（Office 引用知识库，OS 侧视角）；本教程集聚焦 Office 产品自身，互链用文字说明不写跨仓相对路径。
- 六编辑器桌面齐全；web/dsh/插件形态五编辑器（无 HTML）。
