## 一句话说明

不配任何 API Key 也能用 AI 的第二条路：登录察元AIOffice 内置账号后，模型请求走官方代理（Claude 系模型走 Anthropic 协议端点、其余走 OpenAI 兼容端点，密钥由主进程注入，用户全程不见 Key）；登录同时解锁主页「察元AIOffice Projects」云端项目页——你在网页端用 AI 创建的文档/表格/演示项目列表，点击即在浏览器中继续编辑。

**现役状态（2026-10-30，main v1.0.14）**：登录链路与云端项目页**功能在位**，但登录入口整体开关 `USER_LOGIN_READY = false` 处于关闭——模型设置里不出现「察元AIOffice 登录」卡、主页左上不出现 Projects 入口、云端项目不可用态只显示中性「加载失败」文案。功能开工时开关改回 `true` 即全部恢复。本篇步骤描述的是在位形态，入口开放后照做即可。

## 适用场景

- 完全不想折腾 API Key，希望开箱即用 AI（README「内置官方账号登录开箱即用」的说法即指本功能；当前版本该入口尚未开放）；
- 在网页端创建过 AI 项目，想在桌面端看到它们并一键回浏览器继续编辑；
- 想了解登录后模型请求怎么走、凭据存哪。

典型提问（chabot 语料视角）：

- 「不用 Key 能用 AI 吗？」
- 「怎么登录察元AIOffice 账号？」
- 「网页端做的项目在桌面端哪里能看到？」

## 前置条件

- 桌面形态（登录流程会调起系统浏览器授权，web 形态隐藏登录卡）；机器联网。
- 当前版本登录入口未开放（见「现役状态」）；开放后无需任何密钥准备。

## 操作步骤

**第 1 步 · 打开「察元AIOffice 登录」卡**

- 主页左下角账号行齿轮按钮「**设置**」→ 左栏「**模型设置**」；登录功能开放时，左侧目录的「API 聚合」分组会出现「察元AIOffice」行，点开即登录面板：标题「**察元AIOffice 登录**」，说明原文：「登录后可使用默认模型与云端工具（网页/图片搜索、兜底生图）。不登录也能使用自己配置的任何模型。」
- 状态行显示登录态：未登录显示「**未登录**」+ 主按钮「**登录**」；已登录显示「**已登录：<邮箱>**」（无邮箱时仅「已登录」）。

**第 2 步 · 设备码登录（浏览器授权）**

1. 点「**登录**」：应用向平台申请一个设备码，并**自动打开系统浏览器**进入授权页；无需手动输入任何码。
2. 在浏览器里完成账号登录并批准授权。
3. 应用端每约 2 秒轮询一次授权结果：批准后自动取得 30 天期凭据，并铸出一把名为 `chaoffice` 的 API Key 存入本机 `~/.chaoffice/auth.json`（刻意独立存放，不受其他配置文件覆盖影响）；重新登录会自动吊销上一把 Key。
4. 回到设置：卡片状态行变为「已登录：<邮箱>」，登录完成。等待期间再点一次「登录」会重开一轮新设备码（旧码作废）。

**第 3 步 · 勾选内置模型（勾选即启用）**

- 登录后进入「察元AIOffice」面板会自动拉取一次平台模型列表（提示原文：「模型列表实时获取自平台接口，勾选即启用」；也可手动点「**获取模型列表**」重拉）。
- 勾选任一模型即启用内置账号档（勾选动作本身就是启用开关）；勾选的对话模型进入 AI 面板选择器，未指定当前模型时自动落到第一个可用对话模型。列表同样来自接口实时数据，无内置名单。
- 请求路由：模型 id 以 `claude` 开头的走 Anthropic 协议端点（保留图片输入保真），其余走 OpenAI 兼容端点；官方代理的 Gemini 端点已下线，旧配置里的 gemini 系模型 id 加载时自动改写到 claude 系现役 id。

**第 4 步 · 查看云端项目**

- 登录后主页左栏顶部出现「**察元AIOffice Projects**」入口，点击进入云端项目页；副标题原文：「在网页端用 察元AIOffice AI 创建的项目。编辑在浏览器中继续——点击任意项目即可打开。」
- 顶部控件：类型筛选（「**全部 / 文档 / 表格 / 演示**」）、「**刷新**」按钮、搜索框（「搜索 N 个项目…」，按标题本地过滤）。
- 列表两列：「名称」（文档/表格/演示对应 docx/xlsx/pptx 图标）与「修改时间」——点「修改时间」列头弹出排序菜单「**最近 / 最早**」。
- 每次进入页面自动后台同步：本地缓存先秒开、同步完成后替换；大账号最多同步 1000 条（每页 100）。缓存与账号绑定（按密钥哈希做属主标记），换账号或退出登录后另一账号读不到前者列表。
- 点击任意项目行：用系统浏览器打开该项目页（悬停提示「**在浏览器中打开**」）；列表超出 100 条时底部有「**加载更多**」按钮，每按一次多显示 100 条。过滤/搜索/排序都在本地完成，不发请求。

**第 5 步 · 退出登录**

- 退出通道在位：退出会吊销服务端 Key、删除本机 `~/.chaoffice/auth.json`，并清空该账号的云端项目缓存（退出 UI 同样随登录开关整体隐藏）。

### 验证

- **当前版本**（开关关闭）：设置▸模型设置左栏目录**不出现**「察元AIOffice」行、主页左上无 Projects 入口——这是预期行为，不是故障。
- **入口开放后**：登录成功后 `~/.chaoffice/auth.json` 文件出现；模型设置出现登录卡且状态为「已登录」；主页左上出现「察元AIOffice Projects」，进入可见网页端项目列表。

## 常见问题

**Q1：设置里为什么找不到登录入口？**
当前版本登录功能未开放（`USER_LOGIN_READY = false`），入口整体隐藏，模型设置目录行、登录卡与云端项目入口都不可见。README「内置官方账号登录开箱即用」描述的是该功能开放后的形态；现阶段请用 O08 的 BYOK 或 O10 的本地模型。

**Q2：不用 Key 能用 AI 吗？**
两条路：内置账号登录（走官方代理，入口开放后可用，见本篇）；或本地免 Key 模型（Ollama 等，O10，当前即可用）。完全无模型时，文档编辑/转换/导出等传统功能照常离线可用。

**Q3：登录卡里模型列表拉取失败？**
内置模型列表实时来自平台接口。点「**获取模型列表**」重试；仍失败多为网络或平台侧问题，稍后再试。接口返回什么就显示什么，没有内置兜底名单。

**Q4：云端项目页一直显示「加载失败，请稍后重试。」？**
两种可能：登录态缺失（当前版本未开放登录，未登录态就显示这个中性文案，点「重试」不会成功）或平台接口暂时不可用。入口开放并登录后，若仍失败先点「刷新」重新同步。

**Q5：云端项目会下载到本机吗？**
不会。云端项目只是网页端项目的列表镜像（标题/类型/时间/链接），点击用浏览器打开网页继续编辑；桌面端打开的本地文件与此互不相干。

## 形态差异

- **web/浏览器形态与 dsh 插件形态**：两者只含五编辑器（docs/sheets/slides/pdf/markdown，无主页壳）——模型设置表单随编辑器可用，但登录卡隐藏（登录仅桌面形态），云端项目页属主页壳功能、此两形态不存在。
