## 一句话说明

Sheets 表格编辑器顶部的功能区按 Excel 习惯分成七个常驻页签（开始、插入、页面布局、公式、数据、审阅、视图），选中图表/表格/形状/图片时还会临时多出上下文页签；其中「数据」页签集中了数据透视表、切片器、日程表、高级筛选、合并计算、模拟分析、分列、快速填充、删除重复值、数据验证等数据工具。表格的读写与重算由内置的 Rust 计算引擎（基于 calamine + IronCalc 的 xlsx-sidecar 独立进程）承担，界面只是它的驾驶舱。

## 适用场景

- 刚从 Excel/WPS 迁过来，想找到透视表、合并计算、单变量求解这些数据工具在哪个页签哪个组；
- 手上有一张流水表，想按维度汇总、按月份切片筛选、给重复行去重；
- 想知道底部工作表标签的右键菜单都能做什么、状态栏的统计和缩放怎么用。

典型提问（chabot 语料视角）：

- 「Sheets 怎么做数据透视表？字段在哪里拖？」
- 「合并计算/单变量求解在哪个菜单里？」
- 「怎么把一列按逗号拆开？有没有快速填充？」

## 前置条件

- 在察元AI Office 中用 Sheets 编辑器打开了或新建了工作簿（见 [O03](./O03-新建与打开文件.md)）。
- 大部分数据工具要求工作簿**完整加载**：超大文件默认流式加载（只载入看过的区域），此时删除重复值会提示「删除重复项需要完整加载模式」，「分列」按钮提示「拆分单列文本（需完整加载的工作簿）」——按提示先完整加载或改用较小的文件。
- 透视表、切片器、日程表需要先打开 XLSX 文件（基于文件里的透视表工作）。

## 操作步骤

**第 1 步 · 认识功能区与编辑区骨架**

1. 页签行常驻七个页签，顺序固定：**开始 / 插入 / 页面布局 / 公式 / 数据 / 审阅 / 视图**。没有「文件」页签——文件命令（打开/保存/另存为/导出 PDF/打印）在系统应用菜单和工具栏图标里。
2. 四个**上下文页签**按选中对象出现，不打断当前所在页签：选中图表出现「**图表设计**」、光标进入表格（Table）出现「**表设计**」、选中可编辑形状出现「**形状格式**」、选中浮动图片出现「**图片格式**」；取消选中后自动消失。
3. 表格区上方是**名称框行**：左侧名称框显示当前单元格地址（如 B3），右侧「**▾**」按钮打开「定位」对话框（快捷键 ⌘G / Ctrl+G，或 F5）；公式栏在「**视图**」页签「显示」组用「**编辑栏**」开关显示/隐藏（⌘U / Ctrl+U 收起展开）。
4. 底部是**工作表标签条**。在标签上**右键**打开菜单：「**插入…**」「**删除**」「**重命名**」「**移动或复制…**」「**保护工作表…**（/撤销工作表保护…）」「**工作表标签颜色**」「**隐藏**」「**取消隐藏…**」「**选定全部工作表**」（成组后多「**取消成组工作表**」）。Ctrl/⌘+点击、Shift+点击可把多张表成组，删除/隐藏/标签颜色会作用于整组；成组时至少保留一张可见表，否则弹「工作簿至少要包含一个可见工作表。」拦截。
5. 最底部**状态栏**：左侧是操作消息；选中有数据时中间显示**选区统计**（求和、平均值等）；右侧是 50%–400% 的**缩放滑杆**加当前百分比。

**第 2 步 · 「数据」页签逐组解剖**

- 「**数据透视表**」组：「**数据透视表**」（副标题「OOXML 数据透视表」）、「**刷新**」（光标在透视表内时提示「重算当前透视表」，否则提示「选中透视区域后刷新」）。
- 「**获取数据**」组：「**从文本/CSV**」（把 CSV/文本文件导入到当前选区）、「**合并工作簿**」（把其他 Excel 文件的工作表并入当前工作簿，公式转数值）、「**全部刷新**」（刷新全部透视表）。
- 「**排序和筛选**」组：「**排序**」下拉（升序/降序/自定义排序…）、「**筛选**」（切换 ⇧⌘L；Windows 下 Ctrl+Shift+L）、「**清除**」「**重新应用**」「**高级**」（对某列应用自定义筛选条件，见第 4 步）。
- 「**数据工具**」组：「**分列**」下拉（按逗号/分号/空格/制表符拆分单列文本）、「**快速填充**」（根据 1-2 个示例填充，快捷键 ⌘E 或 Ctrl+E）、「**删除重复值**」（在选区内）、「**数据验证**」（规则面板）、「**合并计算**」（合并多个区域）。
- 「**预测**」组：「**模拟分析**」下拉：「**单变量求解**」（对目标值反解输入）与「**数据表**」。
- 「**分级显示**」组：「**组合**」下拉（组合行/组合列/隐藏明细/汇总行位置）、「**取消组合**」下拉、「**分类汇总**」（每组小计加总计）。

**第 3 步 · 数据透视表：从创建到字段窗格**

1. 选中含**表头行**、至少 2 行的源数据区域，点「数据」→「**数据透视表**」。若没选够会提示「请先选中源数据区域（含表头行，至少2行），再打开数据透视表。」
2. 「**创建数据透视表**」对话框：「**源区域**」已按选区只读回显；在「**目标起始单元格**」填如 `E1` 的地址，点确定。成功后状态栏提示「已在 E1 创建透视表——保存时写入文件，保存后即可使用切片器、日程表和刷新。」
3. 同时打开「**数据透视表字段**」任务窗格：上方是源字段列表，下方是「**筛选器 / 列 / 行 / 值**」四个拖放区。字段可拖入拖出或在区间移动；值字段的「值字段设置」对话框里可选聚合方式（求和/计数/平均值/最大值/最小值等）与「**显示方式**」（常规/占总计%/占行汇总%/占列汇总%/差异…等）；字段可设分组（按年/按季度/按月/按区间），并可设标签筛选（等于/包含/开头是）。
4. 「**插入**」页签「表格」组还有「**编辑数据透视表**」（副标题「更改字段」，改字段布局）与「**表格**」（副标题「真实 Excel 表格」，创建真正的 Excel 表格对象）。
5. 改完点 ⌘S 保存，透视表连同布局写入 xlsx；Excel 打开时可重建缓存、继续编辑。
6. 基于透视表还能加**切片器/日程表**（「插入」页签「筛选」组，见下）与**数据透视图**（见 [O24](./O24-Sheets图表与可视化.md)）。

**第 4 步 · 切片器、日程表与高级筛选**

- **切片器**：光标放在透视表输出区内，「插入」→「筛选」组→「**切片器**」，弹「**插入切片器**」列出该透视表的维度字段（行/列/报表筛选字段），点一个字段即生成切片器面板；点选面板里的成员即筛选透视表（可多选，全选=不筛选）。注意：切片器控件本身目前只存在于当前会话，不写入文件——但筛选结果（隐藏成员）会随透视表刷新写入，Excel 打开看到的是同样的筛选结果，只是没有切片器控件。
- **日程表**：同组「**日程表**」→「**插入日程表**」列出透视表的日期字段，点选月份即按日期范围筛选（Shift+点选扩展范围）；面板上有「**清除筛选(显示全部)**」与「**删除日程表(恢复全部成员)**」。同为会话内控件，筛选结果随透视表写入。
- **高级筛选**：「数据」→「排序和筛选」组→「**高级**」，弹「**高级筛选**」对话框：选「**列**」，填「**条件 1**」（运算符：等于/不等于/大于/大于等于/小于/小于等于 + 值），可加「**条件 2**（可留空）」并以「**与 AND**」或「**或 OR**」连接，确定后套用为该列的自定义筛选。需要先在数据上开启「筛选」（否则提示「筛选区域中没有可用的列」）；最多两个条件。

**第 5 步 · 合并计算、单变量求解与分类汇总**

- **合并计算**：「数据」→「**合并计算**」。对话框：「**函数**」（求和/计数/平均值/最大值/最小值）、「**引用位置**」（如 `Sheet1!A1:C5`，输入框旁的 ⌖ 折叠按钮可收起对话框到表格里拖选区域）+「**添加**」，多个源引用列在「所有引用位置」；勾「**标签位置：最左列**」则按首列标签匹配行（要求每个区域至少两列），不勾则按位置逐格合并。结果落在活动单元格起的位置，是**引用源区域的实时公式**——源数据改了结果跟着变。
- **单变量求解**：「数据」→「模拟分析」→「**单变量求解**」。对话框三字段：「**目标单元格**」（预填当前单元格，须含公式）、「**目标值**」（数字）、「**可变单元格**」（须是数字或空白）；点「**求解**」异步求解，对话框内显示「找到解:可变单元格 = …（含达到的目标值）」或「未收敛,已恢复原值…」。求解过程对可变单元格的每一步猜测都是可撤销的编辑记录，完成后整轮可一次撤销。
- **数据表**（模拟分析第二项）：选好结果区域后打开「**数据表**」对话框，填「**行输入单元格**」「**列输入单元格**」做双变量敏感度表。
- **分类汇总**：先按分类字段排序并选中数据，点「数据」→「**分类汇总**」。对话框：「**分类字段**」「**汇总方式**」（求和/计数/平均值）、「**选定汇总项**」；确定后每段相同值之后插入一行 SUBTOTAL 小计，末尾加总计行。

**第 6 步 · 分列、快速填充、删除重复值、数据验证**

- **分列**：选中要拆的文本列，「数据」→「**分列**」下拉选「**按逗号拆分**/按分号/按空格/按制表符」，一击把单列拆成多列。
- **快速填充**：在目标列先手工填 1-2 个示例（示例要能由左侧列拼出来），选中目标列空区按 **⌘E / Ctrl+E** 或点「**快速填充**」，按示例规律填完剩余行；规律识别不出会提示「没能从示例中识别出规律……多填一个示例试试」。Flash Fill 需要目标列左侧有数据列、至少两行数据。
- **删除重复值**：选中数据区，「数据」→「**删除重复值**」，对话框说明口径：「删除选区中与前面行重复的行（比较所有列，忽略字母大小写），其余行上移。」可勾「**数据包含标题**」，点「**确定**」执行。
- **数据验证**：「数据」→「**数据验证**」打开数据验证规则面板，给选区设置输入规则（如下拉选项、数值范围），面板里管理已有规则。

### 验证

1. 建一张含表头的数据表做透视表后，在源数据追加一行，点「**刷新**」（提示「重算当前透视表」）——透视表按新数据重算；⌘S 保存后用 Excel 打开同一文件，透视表布局与筛选结果一致。
2. 合并计算完成后，点结果区任一单元格，编辑栏应显示引用源区域的公式（如 `=SUM(Sheet1!B2,Sheet2!B2)` 形态的实时公式）。
3. 快速填充：删掉填充结果按 ⌘Z 可整体撤销；示例改动后重按 ⌘E 结果跟随。
4. 底部标签右键菜单项与第 1 步所列一致；状态栏缩放滑杆拖到 200% 后网格字号随之放大。

## 常见问题

**Q1：点「删除重复值」提示「需要完整加载模式」？**
这个工作簿太大，当前只做了流式加载（网格里只有你看过的区域有数据）。按提示确认完整加载整个工作簿后再执行；「分列」「筛选」等需要全量数据的工具同理。

**Q2：切片器/日程表保存后在 Excel 里怎么不见了？**
切片器与日程表控件目前只存在于会话内（OOXML 的 slicer 部件尚未写入文件），但它们对透视表做的筛选会随保存写入——Excel 打开看到的是同样的筛选结果，只是没有这个可视化控件。

**Q3：透视表提示「透视表布局与输出区不一致——需要在 Excel 中刷新后才能重算」或「该透视表暂不支持编辑」？**
这类提示出现在打开别人文件里的透视表时：紧凑布局、值字段位于行轴、特殊聚合方式（如乘积/数值计数）等形态暂不支持自动重排。按提示在 Excel 中刷新一次再回来，或改用「数据透视表→刷新」重算。

**Q4：快速填充没反应？**
三个前置条件缺一不可：目标列**左侧**要有数据列、数据至少两行、目标列已填 1-2 个示例。满足后再按 ⌘E。

**Q5：合并计算选了最大值/最小值，提示「不支持最左列标签模式」？**
最大值/最小值只支持按位置合并。去掉「标签位置：最左列」勾选，或换求和/计数/平均值。
