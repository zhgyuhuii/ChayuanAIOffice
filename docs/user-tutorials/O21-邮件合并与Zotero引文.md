## 一句话说明

「**邮件**」页签做邮件合并：拿一个 docx 当模板、一份 xlsx/csv 当收件人列表，把每条记录填进模板批量生成文档（每条一个文档，或全部合并成一个）；「**引用**」页签管引文——「引文与索引」组自带一套轻量引文管理（添加新源、插引文、插书目），「Zotero」组则连接本机 Zotero 桌面程序插引文并维护参考文献表。

## 适用场景

- 通知书、证书、工资条、慰问信这类「一份模板 × N 个人」的批量套打；
- 名单在 Excel 里维护，想按行批量生成 docx 并按人命名存档；
- 写论文/报告要插引文、配参考文献表：文献少用自带的「插入引文 / 添加新源」，文献多、要选样式用 Zotero。

典型提问（chabot 语料视角）：

- 「批量套打怎么做？」
- 「xlsx 里的名单怎么按行批量生成通知书？」
- 「怎么用 Zotero 插入引文并生成参考文献表？」

## 前置条件

- 在 Docs 编辑器中打开一个已保存的 .docx 模板文档（合并字段插在它里面；「邮件」页签各按钮在无文档时置灰）。
- 邮件合并的数据源是**本机的 .xlsx 或 .csv**：第一张工作表（或 CSV 首行）的**第一行是列名**，列名即合并字段；列下面的每行是一条记录。
- Zotero 引文需要本机装有 **Zotero 桌面版**并保持运行（命令通过本机集成端口 127.0.0.1:23116 与它通信）。

## 操作步骤

**第 1 步 · 「开始邮件合并」——选数据源**

1. 点「邮件」页签「**邮件合并**」组的「**开始邮件合并**」（悬停提示「选择数据源、插入合并字段、预览并合并」），弹出「**邮件合并**」面板。
2. 点「**选择收件人列表…**」，在文件对话框里选一个 .xlsx 或 .csv（对话框标题「选择收件人列表」，类型过滤「Excel 或 CSV」）。
3. 读取成功后，面板「数据源」区显示文件名，状态栏提示「已加载数据源 {name}（{n} 条记录）」；「合并字段」区列出所有列名。
4. 列名规则：空列名自动补成 `Column1`、`Column2`…；两列重名时第二列自动改成 `Name2` 这种「原名＋序号」，互不打架。

**第 2 步 · 「插入合并字段」——在模板里挖坑**

1. 把光标放到模板里该填内容的位置。
2. 两个入口任选：页签上「**插入合并字段**」▾ 从「合并字段」列表点字段名；或面板「合并字段」区直接点字段按钮。
3. 该字段以 MERGEFIELD 域的形式插到光标处（域指令形如 `MERGEFIELD "姓名" \* MERGEFORMAT`，与 Word 写出的域一致）；逐个字段重复，把模板挖完。

**第 3 步 · 「预览结果」——逐条翻看效果**

- 面板「预览结果」区用「**上一条**」「**下一条**」翻记录，中间显示「第 {n} 条，共 {total} 条」；预览区直接显示这条记录填进模板后的**纯文本效果**。「邮件」页签上也有同款「上一条 / 下一条」按钮（组标签同步显示当前记录号；未选数据源时显示「尚未选择数据源」）。

**第 4 步 · 「完成并合并」——批量产出文档**

1. 面板「合并输出」区二选一（默认选中前者）：
   - 「**每条记录一个文档**」：套打信函模式，每条记录生成一个 .docx；
   - 「**所有记录合并为一个文档**」：每条记录的成品依次排在同一文档里（各占一页）。
2. 选「每条记录一个文档」时多一个「**文件名格式**」输入框（占位提示「留空则使用第一个字段」）：填数据源的列名（如 `姓名`）就用该列的值命名；填别的文字就是字面名，其中可嵌 `{列名}` 取值（如 `通知-{编号}`）；文件名里的非法字符会被替换成下划线。
3. 点「**完成并合并**」：
   - 单文档：弹出「另存为」对话框，选位置保存这个 .docx；
   - 每条一个文档：弹出**选择文件夹**对话框，所有文档写进你选的文件夹；两行记录取到的名字相同时自动排成 `name.docx`、`name-2.docx`、`name-3.docx`，不会互相覆盖。
4. 成功后面板显示「已合并 {n} 个文档」。合并产物按模板原样序列化——模板的样式、节、页眉页脚、图片都保留，产物里不再有域代码。

**第 5 步 · 「引用」页签「引文与索引」组——自带引文管理（不依赖 Zotero）**

1. 「**插入引文**」▾：下拉里列出已添加的源（每项显示「(作者, 年份) 标题前 12 字」），点一条即在光标处插入形如 `(王明, 2026)` 的引文；下拉末项「**添加新源…**」打开「**创建源**」对话框。
2. 「创建源」对话框逐字段：「源类型」下拉（书籍 / 期刊文章 / 网站 / 报告 / 其他）、「作者」（占位提示「姓, 名(如:王, 明)」）、「标题」（必填）、「年份」（占位 2026）、「出版者」——选「期刊文章」时标签变「期刊名称」、选「网站」时变「网站名称」并多出「URL」输入框。点「**添加**」保存；源会自动编一个 tag（取作者/标题前几字＋年份，重名加 `_2`）。
3. 「**书目**」：在光标处插入「**参考文献**」标题＋每源一行的文献表（作者. (年份). 标题. 出版者. URL 简单 APA 风格）；一个源都没添加过会提示「尚未添加任何源。请先通过"插入引文 → 添加新源"创建。」。
4. 源列表以 Word 同款书目源格式（`b:Sources` XML）随文档保存在 customXml 部件里，保存后这份文献表在 Word 里也能识别。

**第 6 步 · 「引用」页签「Zotero」组——连接 Zotero 插引文**

「引用」页签另一个组「**Zotero**」有四个入口（都要 Zotero 正在运行）：

1. 「**Zotero 引文**」：在光标处添加引文（悬停提示「使用 Zotero 添加引文；光标在现有引文中时可编辑」）——点击后命令交给本机 Zotero 执行，按 Zotero 界面的提示完成选择；光标落在已有引文里再点，可编辑这条引文。
2. 「**Zotero 文献表**」：在光标处插入/更新参考文献表（悬停提示「使用 Zotero 添加或编辑参考文献表」）。
3. 「**刷新**」：按文档里全部引文域重刷引文标注与文献表（悬停提示「刷新全部 Zotero 引文和参考文献表」）。
4. 「**文档设置**」▾：「**文档首选项**」「**移除域代码**」两项，都由 Zotero 接管执行，按 Zotero 界面提示完成。
5. 引文在文件里以 Word 域（`ADDIN ZOTERO_ITEM`）保存，参考文献表的文档偏好存在文档自定义属性（docProps/custom.xml 的 ZOTERO_PREF）里，保存后 Word/WPS 的 Zotero 插件可继续编辑。
6. 限制（会弹窗明说）：此文档的**脚注或尾注里含有 Zotero 引文**时，Zotero 命令整体停用，提示「此文档的脚注或尾注中含有 Zotero 引文，察元AIOffice 目前还不能更新它们。为保持参考文献表完整，已停用此文档的 Zotero 命令。」。

### 验证

1. 选完数据源：状态栏出现「已加载数据源 …（N 条记录）」，页签「插入合并字段」▾ 点开能看到列名列表。
2. 插入字段后预览：「预览结果」区随「上一条 / 下一条」变化，第一条记录的值出现在挖坑位置。
3. 合并后：去输出位置数文件——逐记录模式文件数应等于记录数，文件名与「文件名格式」一致；单文档模式是一个多页 .docx。
4. 自带引文：「插入引文」→「添加新源…」建一个源后，下拉里出现这条源；点它光标处出现 `(作者, 年份)`；点「书目」得到「参考文献」标题加文献条目。
5. Zotero：点「Zotero 引文」后按 Zotero 界面提示完成添加，文档光标处出现引文标注；「Zotero 文献表」生成与引文对应的参考文献条目。

## 常见问题

**Q1：点 Zotero 按钮弹「无法连接 Zotero。请先启动 Zotero，并保持桌面程序运行。」？**
本机没有 Zotero 在运行，或 Zotero 的文档集成服务没起来（命令走本机 127.0.0.1:23116 端口）。先启动 Zotero 桌面版并保持开着，再回来重试。

**Q2：「合并字段」列表是空的？**
「插入合并字段」按钮在没选数据源、或数据源没有任何列名时置灰。回面板点「选择收件人列表…」重选；同时检查 xlsx 第一张工作表（或 CSV）的第一行是不是列名而不是数据。

**Q3：逐记录合并时想控制文件名怎么办？**
在「文件名格式」里填一个列名（每条记录用该列的值命名），或填模板文字嵌 `{列名}`（如 `合同-{编号}`）；留空则用第一个字段的值。两个值相同不会覆盖——后者自动加 `-2`、`-3`。

**Q4：脚注里已经插过 Zotero 引文的文档，为什么 Zotero 命令都点不动？**
这是有意的保护：脚注/尾注里的引文域目前读不到，继续跑命令会让这些文献从参考文献表里悄悄消失。产品选择停用命令并弹窗说明（见第 6 步第 6 条），保持文献表完整。

**Q5：自带引文和 Zotero 引文是一套吗？**
不是。第 5 步的「插入引文 / 添加新源 / 书目」是察元AI Office 自带的轻量引文管理，插的是普通文字引文；第 6 步的「Zotero」组走 Zotero 桌面程序，插的是 Zotero 域，能随文献库刷新。两套互不相通，一篇文档建议只用一套。

**Q6：合并出来的文档还是模板吗，会带着合并域吗？**
合并产物是把每条记录的字段值直接写进内容、再按模板原样序列化的普通 docx——模板的样式、节、页眉页脚、图片都保留，产物里不再有 MERGEFIELD 域代码。
