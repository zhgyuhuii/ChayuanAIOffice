## 一句话说明

HTML 编辑器让你像改幻灯片一样改网页：左边源码、右边实时预览，在预览里单击选中元素就能改文字、调样式、删复制挪位置；AI 助手可以按简报从零生成整页或按选中元素提修改；保存时只把你改到的地方写回源码，没动过的部分一字不动；还能导出 Word/PDF/单文件 HTML。

## 适用场景

- 不会写 HTML，但要做一张活动海报页/数据报告页/落地页，想让 AI 先出稿再自己微调；
- 拿到别人的 .html 文件，想改几处文字和颜色，不想通读源码找标签；
- 需要把一个网页变成能发给别人的单个 .html 文件（图片全部内嵌），或转成 Word/PDF。

典型提问（chabot 语料视角）：

- 「HTML 预览里点一下元素就能直接改字吗？面包屑是什么？」
- 「图片怎么去背景/裁剪？替换图片要保存吗？」
- 「导出的单文件 HTML 是什么？为什么有资源内嵌失败的提示？」

## 前置条件

- 仅桌面壳形态提供 HTML 编辑器（web/浏览器与 dsh 插件形态没有 HTML 编辑器，见 [O47](./O47-dsh插件与web形态.md)）。
- AI 相关步骤需要已配置模型（见 [O08](./O08-模型供应商BYOK.md)）；不用 AI 纯手动编辑不依赖模型。
- 「预览」视图中相对路径的图片/样式要文件保存后才能显示（状态栏会提示「保存文件后，相对路径的图片和样式才会在预览中显示」）。

## 操作步骤

**1. 新建/打开与「插入骨架」**

- 从主页「新建 HTML (.html)」或打开 .html/.htm 进入（见 [O03](./O03-新建与打开文件.md)）；空白页编辑区为空；
- 工具条「更多」菜单里点「插入骨架」：把一页标准 HTML 骨架写进空白文档——`<!DOCTYPE html>`、按界面语言设置的 `lang`、`<meta charset="UTF-8">`、`<title>` 与空 `<body>`（页面有内容后该按钮置灰，避免重复塞骨架）。

**2. 三种视图与状态栏**

- 工具条右侧一组三个页签：「预览」（整幅页面）、「分栏」（左源码右预览）、「源码」（整幅代码，CodeMirror 高亮）；「查找和替换 (⌘F)」作用于源码文本——在预览视图触发时会自动切到「分栏」让源码可见（区分大小写/全字匹配/替换/全部替换）；
- 状态栏：源码视图显示「行 {n}，列 {n}」与字符数；右侧「设备」下拉切「桌面/平板/手机」三种预览宽度。

**3. 插入元素（工具条「插入」组）**

- 「标题」「段落」：直接插入带占位文字的元素（「新标题」「在此输入文字。」）；
- 「图片」：从本机选图插入；点右边的下拉箭头改「图片链接…」——填 `https://` 地址插入网络图片；「插入」确认；
- 「表格」：弹出 8×10 选格器，悬停显示「{r}×{c} 表格」，点击插入；
- 「更多」菜单：「列表」「按钮」「区块」「分隔线」，以及「插入骨架」；页面没有 `<body>` 时提示「页面没有 <body>，无法插入元素」。

**4. 预览检查器（在预览里直接选中/改字）**

- 预览里**单击**元素即选中（选中元素出现高亮框与浮动工具栏）；**双击**文字直接就地编辑（提示文案：「单击预览中的元素选中，双击编辑文字」，显示在面包屑区域）；
- 面包屑（元素路径）：显示选中元素的祖先链（如 `div#app`、`section.hero`），点某一节选中那个祖先元素；
- 页面脚本动态生成的元素无法回写源码：面包屑标「脚本生成」，提示「此元素由页面脚本生成，源码中不存在；请通过源码或 AI 修改」；脚本后来改动过的元素标「脚本已改动」，提示「页面脚本改动过此元素，写回源码的修改可能被脚本覆盖」。

**5. 元素工具栏（选中元素后浮出）**

- 文字：粗体/斜体、字号 −/+、颜色；
- 图片元素另有：「替换图片」「裁剪」「去除背景」（自动从图片边缘采样背景色，「容差」滑块控制去除范围，实时预览去除比例）、水平翻转/垂直翻转/向左旋转/向右旋转、锁定宽高比、重置大小；
- 结构：「上移」「下移」「复制元素」「删除元素」；
- 「样式面板」打开右侧完整样式面板；「AI 修改」针对选中元素提修改（见第 7 步）。

**6. 样式面板**

- 分区：文字排版（字号/字重/对齐）、尺寸（宽度/高度/圆角）、盒模型（内边距/透明度）、图片（替代文字/填充方式：拉伸填满/完整显示/裁切填满/原始尺寸）、颜色与背景色（主题颜色/标准色/其他颜色…）；
- 「自定义样式」直接写 CSS；所有改动实时预览，「还原」撤销本面板的改动，「关闭样式面板」退出。

**7. AI：从生成到微调**

- 快捷行右侧气泡「打开 AI 助手」开合 AI 面板；
- 工具条三个 AI 大按钮：「优化界面」（统一间距/对齐/字号阶梯/配色/响应式，不改文字）、「换风格」（五个方向：极简/编辑排版/科技/活泼/深色，先出简报确认再只改样式）、「AI 总结」；
- 空白页让 AI 从零生成：面板给起步指令（设计一个产品落地页/做一份数据报告页/做一张信息图海报/设计一个个人工作台界面），AI 先出「生成简报」（核心主旨/配色/字体/区块清单）让你确认或修改，「按此生成」后流式写出整页；过程中可能弹「收集需求问卷」（可「跳过调研」/「帮我决定」）；
- 选中元素后「AI 修改」：与 Markdown 编辑器一样（见 [O33](./O33-Markdown编辑与双链图谱.md) 第 8 步）可「加入队列」攒批修改或「立即发送」；生成中断时可选「采用」或「放弃」；每次生成有「版本快照」可「回滚」。

**8. 演示与保存**

- 工具条「演示」下拉：「在当前标签页」（隐去编辑界面只留页面）、「全屏」、「新标签页」；退出按 Esc（「退出演示（Esc）」）；
- 保存（⌘S）/「另存为…」/「自动保存」（每 30 秒及窗口失焦时）；
- 保存只写回你改动的片段：编辑以「源码补丁」落盘——每处改动是一次连续区间的替换，没动过的源码一字不动；BOM、换行风格（CRLF/LF）、文件末尾换行原样保留。

**9. 导出**

菜单「文件」：「导出为 Word…」（页面在真实浏览器渲染后抽取标题/段落/列表/表格等转成原生 Word 内容；图表、图标、装饰盒等没有 Word 对应物的视觉以截图嵌入）、「导出为 PDF…」、「导出为单文件 HTML…」（本地图片引用全部内嵌成 data URL，导出副本可直接发人；有资源无法内嵌时提示「已导出，但有 {count} 个资源无法内嵌（如 {first}）」）、「打印」（⌘P）。

### 验证

1. 新建 HTML → 「更多」▸「插入骨架」：源码出现完整的 doctype/`lang`/charset 骨架；切「分栏」右侧立即渲染出空页面。
2. 「插入」▸「标题」后在预览中双击标题文字改为自己的文案，再切「源码」：能看到刚才只在你改的那一处发生了变化，其余源码未动。
3. 选中一张图片，点「去除背景」调「容差」：预览即时显示抠图效果，「应用」后写回；点「替换图片」换图成功（未保存的草稿会提示「保存文件后才能替换或编辑图片」）。
4. 「导出为单文件 HTML…」把副本发到别的机器/浏览器打开：页面完整显示，不依赖原 assets/ 文件夹。

## 常见问题

**Q1：预览里点了某个元素，却提示「脚本生成」改不了？**
这个元素是页面 JS 运行时插进 DOM 的，源码里没有对应标签，所以无法回写。要么改生成它的脚本源码，要么用 AI 面板描述意图让 AI 改；静态元素不受影响。

**Q2：面包屑提示「脚本已改动」是什么意思？**
页面脚本在你选中后又改过这个元素。此时把可视化修改写回源码，下次脚本一跑就可能盖掉它；建议改脚本本身，或改完别再让脚本碰它。

**Q3：预览里图片/样式没显示？**
相对路径的资源要文件落盘后才解析。保存一次（⌘S），状态栏提示「保存文件后，相对路径的图片和样式才会在预览中显示」消失即正常。

**Q4：导出单文件 HTML 时提示「有 {count} 个资源无法内嵌」？**
内嵌只处理本地相对路径的图片/样式引用；网络图片（http/data: 开头）保持原样不内嵌。无法读取的本地文件会按原引用保留并在提示里给出第一个名字，检查该文件是否存在于文档旁边。

**Q5：导出的 Word 里为什么有的内容是图片？**
HTML 里图表、图标、带复杂装饰的盒子没有可对应的 Word 结构，导出按截图保留外观；正文、标题、列表、表格则是原生可编辑的 Word 内容。

**Q6：可视化改动会打乱我的源码格式吗？**
不会。每处编辑是一次精确的连续替换，补丁式写回；缩进、注释、没动过的代码保持原样，BOM/CRLF/LF/末尾换行也原样保留。
