## 五、通用差异与说明

- **顶部栏**：WPS 有文件菜单/分享/云状态/全局搜索；本项目对应能力分布在快捷按钮（保存/另存/撤销重演/自动保存开关）与宿主 shell（`apps/shell`）。
- **AI 形态**：WPS 的 AI 是独立 ribbon tab（WPS AI / 察元 AI 助理）；本项目 AI 是侧栏面板（帮帮我/润色/美化等预置指令），属产品设计取向差异，不算缺陷。
- **下拉实现**：docs/slides 用 CSS Anchor Positioning 定位的富面板（Electron 43 / 新 Chromium 支持，老浏览器无回退会不可见）；sheets 用原生 `<select>` 覆盖（`MenuSelect`）——能弹但样式是系统原生菜单，与 WPS 富画廊差距大。
- **响应式**：slides 有 PowerPoint 式组折叠（`COLLAPSE_ORDER`，目前仅动画 tab 两组）；docs/sheets 窄窗口走横向滚动。

## 七、顶部菜单（tab 行）一致性对比：三端互查 + 对照 WPS

### 已一致（无需动）

- **tab 行视觉规格**：docs/sheets/slides 三端 `.ribbon-tabs` 均为 `padding: 5px 10px 0; gap: 2px` + 拖拽区 + 红绿灯/窗控 inset（CSS 注释互相引用对齐 slides 度量）。
- **QAT 快速访问**：tab 行左侧 保存/撤销/重做/自动保存 三端同款（sheets 多一个"另存为"）。
- **上下文 tab 命名同构**：docs（表格设计/表格布局/图片格式/形状格式）、slides（tableDesign/chartDesign/pictureFormat/shapeFormat）、sheets（图表设计）——语义一一对应。
- **AI 入口**：三端均为 tab 行右端 AI 面板开关。

### 修复优先级

1. T2（改名，一行 i18n）；
2. T5/T7（切换+动画画廊统一组件，与 六-A2/A3 同一工程）；
3. T6（随 A1/A2/A3 落地）；
4. T1/T3（tab 合并，需产品拍板对齐 WPS 还是 Word）；
5. T8（计时区组件化）；
6. T9（sheets 富下拉，工程量大可分批）；
7. T4（文件入口，需产品拍板）。

## 八、遗留建议（按优先级）

1. 切换效果补"速度（spd/p14:dur）/效果选项（方向）/声音"：需扩展 `patchSlideTransitionXml` 与 `setTransition` op 的参数。
2. slides 动画效果数量与 WPS 差距大（18 vs 100+），可按类逐步补。
3. sheets 图标 emoji → 线性图标库；表格样式/单元格样式做缩略图画廊。
4. docs 样式库目前仅 6 张卡片（正文/标题1-3 + 2 个字符样式预设），可接入文档自带段落样式全量。
5. 下拉面板 CSS Anchor Positioning 增加 `@supports` 回退（老浏览器）。
