# WPS 功能区布局文件说明（_layouts/）

> 拷贝日期 2026-09-10。来源：`/Applications/wpsoffice.app`（v12.1.28492 macOS）
> `Contents/Resources/office6/res/`。**仅作布局规格参考，禁止随产品分发。**

## 这批文件是什么

WPS **自家功能区的完整 UI 声明**，明文 XML，无需解密。WPS 每次渲染功能区就是加载这些文件：
tab 的声明在 `<app>ongmani.kui`（每个 tab 是一个 `Context` 元素，`idMso` 与 Office 同名，
如 `TabHome`/`TabInserts`），tab 内容经 `delayloadPath` **懒加载**对应的 `CT_*.kuip`；
全部命令的注册表在 `<app>common.kuip`；全局 entry 平表在 `<app>entries.kuip`。

## 目录结构

| 目录 | 组件 | 内容 |
|---|---|---|
| `wps_文字/` | Writer | 46 个 tab 布局 + wpscommon/wpsentries/wpsongmani |
| `et_表格/` | **Spreadsheet（Excel 对应）** | 37 个 tab 布局 + etcommon/etentries/etongmani |
| `wpp_演示/` | Presentation | 40 个 tab 布局 + 同构三件套 |
| `pdf_PDF/` | PDF | 34 个 tab 布局 + 同构三件套 |

每个目录里：
- `tab布局_ongmani/CT_Home.kuip` = 「开始」页；`CT_Insert.kuip` = 「插入」页；`CT_TableTool*.kuip` =
  表格上下文工具；命名规则 `CT_*` = Context Tab。文件头部 `<shell component="et" tc="ongmani.ct_home">`
  标明所属组件与用途。
- `<app>common.kuip` = 命令注册表（每个命令的 id、**idMso（与 Office 同名）**、icon 名、文字、快捷键）。
- `<app>entries.kuip` = idPath→命令 的 entry 平表（etentries 4000+ 条）。

## 读布局文件要认识的属性（自适应方案的核心参照）

| 属性/元素 | 含义 | 例子（et_表格/tab布局_ongmani/CT_Home.kuip 实拍） |
|---|---|---|
| `spaceHint` | 空间降级提示，5 级：loose/suitable/**topsuitable**/compact/autocompact | 剪切 `spaceHint="compact"`、复制 `spaceHint="autocompact"` |
| `canHideText` | 窄时允许隐藏文字只留图标 | 粘贴菜单 `canHideText="0"` |
| `controlType` | 控件类型枚举（0 触发钮、2 组合框、5 下拉、6 开关…） | 字体框 `controlType="2"`、加粗 `controlType="6"` |
| `KxSingleRowMergeGroupCommand` | 窄时多组合并进同一行 | `SingleRow_ClipboardWrapper` |
| `minimumWidth` / `fixedWidth` / `horizontalPolicy` | 控件布局硬规格 | 字体框 `minimumWidth="151"`、字号框 `fixedWidth="60"` |
| `fontSizeList` | 字号框内置选项 | `6;8;9;10;...;72` |
| `idMso` | 与 Microsoft Office 同名的命令 id（兼容层关键） | `PasteValues`、`Bold`、`GroupEditing` |
| `rbHotKey` / `shortcutHint` | 功能区键提示 / 快捷键 | `Ctrl+V` |
| `icon="xxx_kd"` | 图标资源名 → 对应 `WPS-icon/` 里的图标文件 | `paste_kd`、`bold_wps_kd` |

## 与自研引擎的关系

chayuan-office 自研 ribbon（`packages/ribbon`）要做 WPS 式自适应，这份声明就是**规格基准**：
空间提示语义（spaceHint 五级 + canHideText）、并单行机制（SingleRowMerge）、
组合框/步进器的宽度规格、分组的组成与顺序，全部可以从这批文件直接查证；
配合 `../_originals/`（图标本体）与 `../prometheus_kso/`（`*_kd.svg` 矢量图标）还原视觉。
