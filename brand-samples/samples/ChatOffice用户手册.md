# ChatOffice 新用户上手手册

> 欢迎来到 ChatOffice 茶园办公。这份手册带你在五分钟内完成安装，并学会三个最高频的动作：新建文档、处理表格、生成演示。
> 本文档即为 ChatOffice Markdown 编辑器的真实渲染样张——全文严格使用 GFM 语法。

## 安装

ChatOffice 提供两种使用形态，按需选择其一即可。

1. **桌面端**：从官网下载安装包，支持 macOS / Windows / Linux，安装即用、离线可用。
2. **Web 端**：浏览器打开工作台地址，登录后直接使用，零安装。

> 提示：团队如需私有部署，选择 Docker 形态，一条 `compose` 命令即可拉起全套服务。

## 五分钟上手

### 新建文档

1. 在工作台点击 **新建**，选择 **文档**。
2. 在弹出的模板页选择 **空白文档** 或从模板库挑选。
3. 开始输入。工具栏遵循 WPS 习惯：常用命令都在「开始」选项卡里。

新文档会自动保存到最近使用的位置；按 `Cmd/Ctrl + S` 可随时手动存盘。

### 处理表格

1. 点击 **新建 → 表格**，进入表格编辑器。
2. 在单元格直接输入数据，公式以 `=` 开头，例如 `=SUM(C2:C10)`。
3. 选中一片区域，在「开始」选项卡里打开 **条件格式**，给数据加上色阶或数据条。

表格支持 400+ 常用函数，与 xlsx 双向兼容——从 Excel 或 WPS 打开过的文件可以直接拖进来。

### 生成演示

演示编辑器内置 AI 生成管线：

1. 点击 **新建 → 演示**，选择 **AI 生成**。
2. 用一句话描述需求，例如「生成一份 10 页的产品介绍，品牌色蓝紫渐变」。
3. 等待大纲出现，调整章节后点击 **生成**。

生成完成后每页都可以继续手工微调，所有元素保持原生可编辑。

## AI 助手

AI 能力在三个层面待命，按需取用：

| 层面 | 入口 | 擅长 |
| --- | --- | --- |
| 首页对话 | 工作台右侧对话栏 | 跨文件问答、起草、汇总 |
| 编辑器助手 | 编辑器右侧 AI 面板 | 选区改写、续写、翻译 |
| 生成管线 | 新建 → AI 生成 | 从一句话到整份成稿 |

模型可在 **设置 → 模型设置** 中切换：云端模型开箱即用，也支持接入本地模型（Ollama / LM Studio 等），让敏感数据不出内网。

## 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Cmd/Ctrl + S` | 保存 |
| `Cmd/Ctrl + Z` | 撤销 |
| `Cmd/Ctrl + F` | 查找 |
| `Cmd/Ctrl + K` | 插入链接（Markdown） |
| `Cmd/Ctrl + B` | 加粗 |
| `Cmd/Ctrl + Shift + F` | 聚焦模式 |

导出为 JSON 的快捷键配置长这样：

```json
{
  "save": "CmdOrCtrl+S",
  "undo": "CmdOrCtrl+Z",
  "find": "CmdOrCtrl+F",
  "bold": "CmdOrCtrl+B"
}
```

## 常见问题

- [ ] **文件打不开？** 确认文件格式在支持列表中（docx / xlsx / pptx / md / pdf / html）。
- [x] **样式和 WPS 不一致？** 在「设置 → 兼容性」里开启严格模式，按 WPS 渲染基线排版。
- [ ] **AI 没有响应？** 检查模型设置中的网络通道；私有部署请确认内网模型服务在线。
- [x] **想回到历史版本？** 云端文档在「文件 → 历史版本」里可预览与恢复。
